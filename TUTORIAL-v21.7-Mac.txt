【第一步：解压】
1. 双击 jirvs-v21.7-src.zip 解压
2. 得到 v216 文件夹

【第二步：安装 Node.js】（如果已安装跳过）
1. 打开浏览器，去 https://nodejs.org
2. 下载 LTS 版本（左边那个绿色按钮）
3. 双击安装，一路点"继续"
4. 安装完，打开"终端"（在启动台搜"终端"）
5. 输入 node -v，按回车
   看到 v18 或 v20 开头的版本号就是成功了

【第三步：安装依赖】
1. 打开终端
2. 输入 cd ，然后把 v216 文件夹拖进终端，按回车
3. 输入 npm install，按回车
4. 等待安装完成（看到 added xxx packages 就是好了）

【第四步：启动服务】
1. 还在终端里（v216 目录下）
2. 输入 node src/server.js，按回车
3. 看到 "Jirvs API listening on :3000" 就是启动成功了
4. 不要关这个终端窗口

【第五步：测试】
1. 再开一个终端窗口（command+N 新建）
2. 测试健康检查：
   curl http://localhost:3000/api/health
   看到 {"ok":true} 就是正常的

【第六步：打开后台页面】
1. 打开浏览器
2. 输入 http://localhost:3000/admin.html
3. 看到"生态管理"菜单就是 v21.7 的新功能

【停止服务】
1. 回到运行服务的终端窗口
2. 按 control+C 停止

【常见问题】
Q: 端口被占用？
A: 先杀掉旧进程：pkill -f "[s]rc/server"，再重新启动

Q: npm install 很慢？
A: 正常，第一次要下载很多文件，耐心等
